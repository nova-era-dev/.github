## Sobre a organização

Este é o espaço oficial de desenvolvimento do **Nova Era Superatacado** no GitHub.

Aqui são mantidos projetos desenvolvidos pelas equipes técnicas da empresa, incluindo sistemas internos, automações de processos, integrações entre plataformas e soluções de apoio às áreas de negócio.

Nosso objetivo é utilizar tecnologia para:

- Automatizar processos operacionais
- Integrar sistemas e plataformas
- Melhorar a disponibilidade de informações
- Reduzir atividades manuais e repetitivas
- Desenvolver soluções internas
- Aumentar eficiência e produtividade

## Organização dos repositórios

Os projetos seguem uma padronização de nomes para facilitar sua identificação.

| Prefixo | Tipo de projeto |
|---|---|
| `rpa-` | Automação de processos |
| `site-` | Sistemas e aplicações web |
| `intg-` | Integrações entre sistemas |
| `exe-` | Executáveis e serviços internos |

Exemplos:

```text
rpa-notas-imobilizado-e-cte-contabil
site-portal-de-switch
intg-assinatura-de-contrato
exe-autohelpne
```

## Segurança

Os projetos corporativos podem envolver integrações e componentes destinados exclusivamente ao ambiente interno.

Não devem ser versionados:

- Senhas
- Tokens
- Chaves de API
- Credenciais de banco de dados
- Certificados privados
- Dados pessoais ou informações sensíveis

Credenciais devem ser armazenadas por meio de variáveis de ambiente ou mecanismos apropriados de gerenciamento de secrets.

---

## Boas práticas

Sempre que aplicável, os projetos devem possuir:

- `README.md`
- `.gitignore`
- Arquivo de dependências
- Instruções de instalação
- Instruções de execução
- Documentação das variáveis de ambiente
- Responsável pelo projeto
