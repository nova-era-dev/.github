## Sobre

Este é o espaço oficial das equipes de tecnologia do **Nova Era Superatacado** no GitHub. Aqui mantemos os sistemas internos, as automações e as integrações que sustentam as áreas de negócio da empresa.

Nosso foco é eliminar tarefas manuais, conectar plataformas e garantir que a informação certa chegue a quem precisa, com agilidade e confiabilidade.

---

## Áreas de atuação

| Área | Escopo | Tecnologias |
|---|---|---|
| **Automação de processos** | RPAs, rotinas agendadas e serviços que executam tarefas operacionais e administrativas | Python, Selenium, APIs, Agendador de Tarefas do Windows |
| **Sistemas web** | Criação e manutenção das aplicações utilizadas pelas áreas internas | React, JavaScript, Node.js, Django, FastAPI |
| **Integrações** | Comunicação entre ERPs, fornecedores e plataformas externas | REST APIs, Webhooks, ETL, Oracle, PostgreSQL |
| **Dados e indicadores** | Coleta, tratamento e disponibilização de dados para a tomada de decisão | SQL, Python, Pandas, Power BI |

---

## Padrão de nomenclatura

Cada repositório recebe um prefixo que identifica sua categoria:

| Prefixo | Categoria | Exemplo |
|---|---|---|
| `rpa-` | Automação de processos | `rpa-conciliacao-fiscal` |
| `site-` | Aplicações web | `site-portal-interno` |
| `intg-` | Integrações | `intg-erp-fornecedores` |
| `exe-` | Executáveis e serviços locais | `exe-assistente-suporte` |

---

## Segurança e boas práticas

Nenhum repositório deve conter credenciais ou informações sensíveis, como senhas, tokens, chaves de API, certificados privados ou dados pessoais protegidos pela LGPD. Esses valores devem ser fornecidos por variáveis de ambiente ou por um gerenciador de segredos.

Sempre que aplicável, cada projeto deve incluir:

- `README.md` com objetivo, instruções de instalação e de execução
- `.gitignore` adequado à stack utilizada
- Arquivo de dependências (`requirements.txt`, `package.json` etc.)
- Documentação das variáveis de ambiente, de preferência com um `.env.example`
- Responsável técnico identificado
